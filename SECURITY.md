# Seguridad

## Reglas generales

- No almacenar contraseñas, tokens, llaves privadas ni secretos en GitHub.
- No versionar archivos de entorno con valores reales ni respaldos de datos sensibles.
- Utilizar variables de entorno o mecanismos seguros para configuración sensible.
- Revisar dependencias y cambios antes de su uso en entornos productivos.
- Revocar de inmediato cualquier credencial que haya sido expuesta.

## Reporte de seguridad

No publicar detalles sensibles en Issues o Pull Requests públicos. Utilizar un canal autorizado y privado para reportar vulnerabilidades o incidentes de seguridad.
