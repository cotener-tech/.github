# Contribución

## Principios generales

- Describir claramente el objetivo de cada cambio.
- Mantener los cambios acotados y revisables.
- Utilizar Pull Requests para revisión cuando corresponda.
- Ejecutar las validaciones y pruebas aplicables antes de integrar cambios.
- Actualizar la documentación cuando el comportamiento o uso cambie.
- No incluir secretos, credenciales, datos sensibles ni información confidencial.

## Pull Requests

Todo Pull Request debe explicar qué cambia, por qué cambia y cómo fue validado.
